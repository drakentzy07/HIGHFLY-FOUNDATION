# F2 — Puente de combate sin clases

Se trabaja con la referencia de API de ClaudeCraft 0.44.7, sin importar su código ni recursos en esta etapa. El Hunter permanece independiente de Warrior, Mage y Rogue.

Objetivo: traducir entidades y posiciones de mundo a objetivos relativos, emitir intenciones de combate para futura validación por el simulador autoritativo, modelar gestos FURY y probar guardado. No afirmar integración 3D ni funcionamiento en Android hasta comprobarlo.
